Hermes Mail

Hermes Mail is a personal, single-user tool. It lets its developer's own AI assistant, running locally on the developer's own computer, read the developer's own email so it can produce a private daily briefing.

It is not a public service. It is not offered to, or usable by, anyone else.

  • Access is read-only: it requests only the Gmail scope gmail.readonly. It cannot send, delete or modify email.
  • All processing happens on the developer's own computer.
