Privacy policy

Last updated: 4 October 2026

Hermes Mail is a personal tool used only by its developer, with the developer's own Google accounts. This policy describes how it handles Google user data.

What data is accessed

With the developer's consent, Hermes Mail uses the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly to read message headers (sender, subject, date), snippets and message bodies from the developer's own mailbox.

How data is used

Email content is used solely to generate summaries and briefings for the developer, on the developer's own computer, using a locally run AI model. It is not used for advertising, profiling, or training of any AI or machine-learning model.

Storage and sharing

  • Email content is not stored on any server and is not transmitted to any third party.
  • OAuth tokens are stored only on the developer's computer, readable only by the developer's user account.
  • No data is sold, shared, or transferred to anyone.

Google API Services User Data Policy

Hermes Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, after which locally stored tokens stop working.
